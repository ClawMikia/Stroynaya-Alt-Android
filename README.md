## ✨ Features

### 📸 Royal Capture & Media Support
- **Full Media Support**: Seamlessly manage both high-resolution photos and videos from your realm.
- **Photo & Video Capture**: Built-in camera support powered by CameraX for capturing every moment of your journey.
- **Kingdom Registry**: Every captured or imported media item is automatically assigned a unique two-word fantasy name (e.g., "Silver Knight", "Eternal Mage") generated by the spirits of the land.

### 🖼️ The Great Library
- **Horizontal Combination**: Select multiple images and "forge" them together into a single horizontal panoramic tapestry—ideal for creating visualization boards of future connections.
- **Advanced Filtering**: Quickly find what you seek with real-time search by name or tags.
- **Flexible View Modes**: Toggle between a dense grid for overview and a detailed list mode for closer inspection.
- **Smart Sorting**: Organise your collection by date, name, or size with arcane precision.

### ⚡ Rapid Import
- **Single Import**: Detailed import screen for individual files with title and description editing.
- **Multiple File Selection**: Quickly select and import multiple images simultaneously from the main dashboard.
- **Folder Import**: Seamlessly import entire folders (images only) to quickly populate your library from existing archives.

### 🎬 Reel Studio & Enchantment
- **Reel Studio**: Stage video projects by selecting and organizing clips for further creation.
- **Image Editor**: Comprehensive photo editing tools with drawing overlay support for adding arcane annotations.
- **Video Playback**: Integrated video player powered by Media3 for smooth viewing of captured reels.

### 📁 Vaults & Albums
- **Custom Albums**: Create and manage custom collections to group your most precious artifacts.
- **Safe Storage**: Organized local storage management ensuring your media remains within the kingdom's bounds.

### 🎯 Sovereign Experience
- **"Red Kingdom" Aesthetic**: A beautiful cyberpunk-inspired theme with strictly red accents, deep abyss backgrounds, and glowing neon elements.
- **Material 3 Design**: Modern, intuitive interface following the latest Google guidelines while maintaining a unique fantasy character.

## 🛠️ Technical Stack

### Core Technologies
- **Kotlin**: Primary programming language (Kotlin 2.0)
- **Android SDK**: Targeting API 35 (Vanilla Ice Cream)
- **Material Design 3**: UI framework with deep customization for the "Red Kingdom" theme.
- **Room Database**: Local data persistence for media metadata and album organization.
- **Manual Dependency Injection**: Managed via `AppContainer` for a clean, decoupled architecture.

### Key Libraries
- **CameraX**: High-performance photo and video capture.
- **Media3 / ExoPlayer**: Industry-standard video playback and media processing.
- **Navigation Component**: Robust fragment-based navigation with a single-activity architecture.
- **Coil**: Modern, coroutine-based image loading with video frame support.
- **Coroutines & Flow**: Reactive programming model for smooth UI updates and background processing.

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone <repository-url>
cd Stroynaya
```

### 2. Open in Android Studio
1. Open Android Studio (Ladybug or newer recommended).
2. Select "Open" and navigate to the `Stroynaya` directory.
3. Wait for the Gradle sync to complete and the realm to be prepared.

### 3. Build and Run
1. Connect an Android device (API 24+) or start an emulator.
2. Click the "Run" button (▶️) or press `Shift + F10`.
